# Vibeify - Web Photo Editor

A sleek, modern web-based photo editor with an Apple-inspired design.

## Features

- **Adjustments**: Fine-tune brightness, contrast, saturation, and blur
- **Transform**: Rotate, flip, and crop your images
- **Filters**: Apply beautiful pre-made filters
- **Effects**: Coming soon!

## Project Structure

- `index.html` - Landing page
- `editor.html` - Photo editor interface
- `styles/main.css` - All styling
- `js/editor.js` - Editor functionality

## UI Components

- Right sidebar for tool categories
- Horizontal panels that slide out from the sidebar when a tool is selected
- Responsive design for mobile and desktop

## Getting Started

1. Clone this repository
2. Open index.html in your browser
3. Click "Start Editing" to go to the editor
4. Upload an image by dragging and dropping or clicking the upload area
5. Use the tools in the right sidebar to edit your photo

## Browser Compatibility

Tested and working on:
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
